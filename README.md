# intelli-class-ai
A web app that produces a full lesson kit (lesson plan + worksheet + quiz + answer key) on demand for any topic. Teachers, tutors, and trainers spend hours preparing each class - lesson plans, worksheets, quizzes. The same structure repeats for every topic. AI can automate much of this work so educators can focus more on teaching.

Generate:

- Lesson Plans
- Worksheets
- Quizzes
- Answer Keys
- learning outcome
- compitencies

Tech Stack:

- Lovable
- React
- Supabase
- n8n
- OpenRouter

## Setup

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

Import workflows into n8n.
